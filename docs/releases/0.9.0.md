# Awuuu 0.9.0

Clipboard history, a redesigned Shelf, Windows file dragging and edge-attached island movement.

## What's changed

- Automatic local Clipboard history for text and images, with search, categories, copy and deletion. Keeps up to 50 items within 20 MB, expires entries after 24 hours and clears on app exit. Pause it in Privacy & history.
- Files and Clipboard share one Shelf page. File previews, Windows icons, original filenames, duplicate-content detection, multi-selection and bulk deletion replace the earlier list. File dragging uses Windows native copy operations.
- Grip and Alt-drag move the island along screen edges. Elastic capsule motion, corner hysteresis, Esc cancellation and recovery from failed movement replace free-flight dragging.
- Left/right docks use portrait layouts and independently saved dimensions. Music, Agents, Chat, Shelf and narrow upload layouts adapt to the available space.
- Shorter, consistent page transitions and reduced-motion support. Fixed clipped selection outlines, leaked agent icons during movement and conflicting Alt/file drag gestures.
- Refined settings organization, setup guidance and saved-state feedback. Connection checks now report actual provider responses instead of treating saved credentials as a successful connection.
- Refreshed Windows media synchronization and quick controls, session terminal handling and agent hooks. AGY/Hermes remain notify-only; supported Claude/Codex approval flows remain separate.

## Availability and remaining limits

- Local Clipboard, Shelf and music controls work without an Awuuu cloud account. End users do not install developer tools or Cloudflare.
- Link/QR sharing is **not available in this build**: the project-operated service has not been deployed/configured. The encrypted sharing client and operator backend source are included for a future activation. Its current limits are 25 MB per file and 24-hour links; bulk sharing creates separate links and can encounter rate limits.
- Native drag-out requires a destination that accepts Windows file drops. Explorer and third-party chat upload targets still need interactive acceptance testing; automated tests do not establish compatibility with every application.
- Online integrations still require their own account/configuration. Read-only connection tests show failures and skip unconfigured services.

## Validation

Frontend tests, TypeScript/Vite build, native clipboard/Shelf/geometry regressions and the local sharing backend tests were checked during development. The installer is signed for Awuuu's updater; this is separate from Windows Authenticode signing.

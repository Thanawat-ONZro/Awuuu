## ให้ owen ลอง
1. **ลากเกาะ:** ลากไปทุกขอบ (ดูน้ำ, การดูดเข้าขอบ, การตั้งขึ้นที่ขอบซ้าย/ขวา) แล้วเปิดเกาะที่ขอบซ้าย/ขวา/ล่าง (ลองดู approval card, หน้าแชต และหน้า Today ในแต่ละขอบด้วย)
2. **ลากไฟล์จาก Explorer** ไปใกล้เกาะตอนซ่อน → เกาะเปิดหน้า drop → ปล่อย → หมารับไฟล์ → ถามเรื่องไฟล์ได้
3. **หน้า Welcome:** ติดตั้ง hook ของ Hermes และ OpenCode จากปุ่ม Set up (ผมยังไม่ได้เขียนอะไรลง config ของคุณ) แล้วกด Got it
4. **`aw`:** กด Add aw to PATH → เปิด terminal ใหม่ → `aw status`, `aw hermes`
5. **แชต:** เปลี่ยน model / effort แล้วดู chip ด้านขวาว่าตรงกับที่เลือกไหม
6. **Today:** ใส่ข้อมูลใน Settings → Everyday (Gmail app password, ลิงก์ iCal, Todoist, เว็บที่อยากเฝ้า, RSS, เมือง) แล้วกด Test
